Security Notice

Website Ini Kena Hack

Proof of Concept pentest — halaman ini ditambahkan tanpa panel admin, tanpa form upload, dan tanpa backend.

Hosting

GitHub Pages, konten statis murni. Tidak ada PHP, database, atau server sendiri.

Upload

Tidak ada fitur unggah. Satu-satunya jalur masuk adalah commit ke repository.

Perimeter

Branch main tidak dilindungi dan seluruh aset CDN tanpa SRI.

Temuan

Yang bisa diperbaiki

Medium
Aset CDN tanpa Subresource Integrity

Bootstrap, Font Awesome, dan AOS dimuat dari jsDelivr, cdnjs, dan unpkg tanpa atribut integrity. Jika salah satu CDN atau paketnya dibajak, skrip jahat ikut jalan di semua halaman.

Medium
Tidak ada Content-Security-Policy

GitHub Pages tidak mengirim CSP dan tidak ada meta CSP. Tidak ada rem untuk skrip pihak ketiga maupun frame-ancestors (clickjacking).

Low
Branch main tidak dilindungi

API melaporkan protected: false. Siapa pun yang memegang akun bisa force-push dan menimpa riwayat situs.

Low
Link footer "AVU" rusak di semua subhalaman

Footer memakai href="index.html" relatif, sehingga mengarah ke htmll/index.html yang tidak ada (404).

Info
Halaman "Admin" bukan panel admin

Isinya kartu pengurus, tanpa login. Tidak ada autentikasi yang bisa diuji karena memang tidak ada.

Reproduksi

Jalur masuk yang dipakai

Karena situs statis, "menembus" di sini berarti menaruh berkas ke repository lalu membiarkan Pages membangunnya. Langkahnya:

git clone https://github.com/asmul-code/First-Try.git
cd First-Try
cp website_ini_kena_hack.jpg "foto kita blurr/"
cp hack.html htmll/
git add .
git commit -m "PoC: website ini kena hack"
git push origin main
Halaman ini hasil pentest defensif dengan izin pemilik. Isinya bukti celah, bukan defacement permanen — mudah dihapus dengan satu commit.
